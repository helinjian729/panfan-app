# Content Review Standards

This document defines the standards for reviewing articles and written content.

---

## 1. Logical Review Dimensions

### 1.1 Argument Clarity

| Standard | Description | Severity |
|----------|-------------|----------|
| Clear Thesis | Main argument is explicitly stated and easy to identify | Critical |
| Defined Scope | Boundaries of the argument are clear | High |
|术语一致性 | Key terms are defined and used consistently | High |

### 1.2 Argument Strength

| Standard | Description | Severity |
|----------|-------------|----------|
| Sufficient Evidence | Claims are supported with adequate evidence | Critical |
| Source Quality | Evidence comes from credible, relevant sources | High |
| Logical Coherence | Arguments flow logically without contradictions | Critical |
| Acknowledged Counterarguments | Opposing views are addressed | Medium |

### 1.3 Common Logical Fallacies

- **Ad Hominem**: Attacking the person rather than the argument
- **Straw Man**: Misrepresenting an argument to easier defeat it
- **False Dilemma**: Presenting only two options when more exist
- **Slippery Slope**: Assuming one event leads to extreme consequences without evidence
- **Circular Reasoning**: Using the conclusion as a premise
- **Hasty Generalization**: Drawing broad conclusions from limited samples

## 2. Structural Review Dimensions

### 2.1 Organization

| Standard | Description | Severity |
|----------|-------------|----------|
| Logical Ordering | Sections follow a natural, coherent progression | Critical |
| Balanced Sections | Related points receive proportional coverage | High |
| Hierarchical Clarity | Major sections and subsections are clearly delineated | High |

### 2.2 Paragraph Structure

| Standard | Description | Severity |
|----------|-------------|----------|
| Unity | Each paragraph addresses one main idea | High |
| Coherence | Sentences within paragraphs flow smoothly | High |
| Adequate Development | Paragraphs are neither too thin nor overly long | Medium |
| Topic Sentences | Most paragraphs begin with clear topic statements | Medium |

### 2.3 Transitions

| Standard | Description | Severity |
|----------|-------------|----------|
| Inter-paragraph | Smooth flow between paragraphs | High |
| Inter-section | Clear bridges between major sections | High |
| Signposting | Use of transitional phrases to guide readers | Medium |

### 2.4 Introductions and Conclusions

**Introduction Checklist:**
- [ ] Hook to capture reader interest
- [ ] Context or background information
- [ ] Clear thesis statement
- [ ] Overview of structure (optional)

**Conclusion Checklist:**
- [ ] Restatement of thesis in fresh language
- [ ] Summary of key points
- [ ] Broader implications or call to action
- [ ] No new major arguments introduced

## 3. Factual Review Dimensions

### 3.1 Data Accuracy

| Standard | Description | Severity |
|----------|-------------|----------|
| Statistics Verified | All numerical claims are accurate | Critical |
| Dates Correct | Events, deadlines, and timelines are accurate | High |
| Names and Titles | People, places, and organizations are correctly named | High |

### 3.2 Source Reliability

| Standard | Description | Severity |
|----------|-------------|----------|
| Primary Sources | Key claims reference original sources | High |
| Source Credibility | Sources are from reputable, authoritative outlets | High |
| Recency | Sources are current enough for the topic | Medium |
| Citation Format | Sources are properly cited | Medium |

### 3.3 Verifiable Claims

All factual claims should be:
1. Traceable to a credible source
2. Consistent with established knowledge
3. Not taken out of context

## 4. Style Review Dimensions

### 4.1 Tone Consistency

| Standard | Description | Severity |
|----------|-------------|----------|
| Uniform Register | Same formality level throughout | High |
| Audience Appropriate | Tone suits the target readership | High |
| No Mixed Signals | Writing doesn't undercut its own points | Medium |

### 4.2 Terminology Consistency

| Standard | Description | Severity |
|----------|-------------|----------|
|术语统一 | Same concept uses same term throughout | High |
| Defined Abbreviations | Abbreviations are defined on first use | Medium |
| No Jargon Overload | Technical terms are explained or minimized | Medium |

### 4.3 Formatting Standards

| Standard | Description | Severity |
|----------|-------------|----------|
| Heading Hierarchy | H1 → H2 → H3 used consistently | Medium |
| List Consistency | Bulleted/numbered lists follow same format | Low |
| Code/Quote Blocks | Properly formatted with language specified | Medium |

### 4.4 Mechanics

| Standard | Description | Severity |
|----------|-------------|----------|
| Spelling | No spelling errors | High |
| Grammar | Correct grammar throughout | High |
| Punctuation | Proper punctuation usage | Medium |
| Typography | Smart quotes, em-dashes, etc. used correctly | Low |

---

## 5. Review Output Format

When conducting a review, use this severity classification:

| Level | Meaning | Action Required |
|-------|--------|-----------------|
| Critical | Fundamentally undermines the article | Must fix |
| High | Significantly impacts quality | Should fix |
| Medium | Noticeable but doesn't majorly impact | Consider fixing |
| Low | Minor polish issue | Optional to fix |
